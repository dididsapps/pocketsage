# Avatar 11 ans — prompts GPT (Chat, mode image)

À faire **dans la même conversation** que l'avatar validé, une planche par message, dans l'ordre.
Envoie-moi chaque planche telle quelle (PNG) : je découpe, j'aligne les pieds et je fabrique les GIF et les bandes « Mon monde ».

---

## 0. Image de référence (à envoyer en premier)

```
Reprends exactement ce garçon de 11 ans (même visage, mêmes cheveux blonds bouclés, mêmes taches de rousseur, même corps, même pantalon jean large, mêmes baskets grises, t-shirt blanc).
Deux changements obligatoires :
1. Style : rendu 3D d'animation, doux et coloré, façon film d'animation pour enfants (pas photo réaliste) : peau lisse, grands yeux expressifs, éclairage studio doux.
2. Veste : garde le blouson teddy bleu marine à manches beiges et rayures aux poignets, mais SANS AUCUN logo, écusson, lettre, texte ni personnage dessus (pas de « P », pas de Snoopy, pas de « Peanuts »). Veste unie.
Image : le garçon en entier, debout, de face, bras le long du corps, sourire léger. Fond transparent, aucun texte. Format 1024 × 1536.
Cette image devient la référence pour toutes les suivantes.
```

---

## Règles communes (à coller au début de chaque planche ci-dessous)

```
Même garçon que la référence 3D validée (même visage, cheveux, tenue sans logo, même style 3D, mêmes couleurs).
Planche 1536 × 1024, fond TRANSPARENT, 6 cases de 512 × 512 (3 colonnes × 2 lignes), une seule image du garçon par case, lue de gauche à droite puis ligne du bas.
Le garçon entier dans chaque case (des cheveux aux baskets), même taille dans toutes les cases, centré, pieds posés sur la même ligne en bas de la case (sauf s'il saute ou s'allonge). Aucun texte, aucun numéro, aucun cadre, aucune ombre au sol, aucun décor.
```

## 1. Mon monde — marche vers l'avant (face)

```
[Règles communes]
Cycle de marche en 6 étapes, vue de trois quarts en plongée légère (jeu vidéo isométrique), le garçon marche vers le BAS À GAUCHE de l'image, on voit son visage.
Les 6 cases forment une boucle fluide : jambes et bras qui alternent, comme une marche normale.
```

## 2. Mon monde — marche vers l'arrière (dos)

```
[Règles communes]
Cycle de marche en 6 étapes, vue de trois quarts en plongée légère (isométrique), le garçon marche vers le HAUT À GAUCHE de l'image : on le voit de DOS (arrière de la tête et du blouson).
Les 6 cases forment une boucle fluide.
```

## 3. Mon monde — 6 poses

```
[Règles communes]
Vue de trois quarts face en plongée légère (isométrique), une pose par case, dans cet ordre :
1. debout, immobile, détendu ;
2. assis sur une chaise invisible (cuisses horizontales, mains sur les genoux) — ne dessine pas la chaise ;
3. allongé sur le dos, endormi, yeux fermés (vue de côté, tête à droite) ;
4. debout, il mange avec une cuillère dans un petit bol ;
5. debout, il fait coucou avec une main levée ;
6. saut de joie, les deux bras levés, les pieds décollés du sol.
```

## 4 à 11. Réactions animées (quiz réussi / raté)

Pour chacune : 6 cases = 6 moments d'un même mouvement, dans l'ordre, qui forment une petite animation en boucle (la case 6 revient presque à la case 1). Vue de face.

### 4. Content — pouce levé

```
[Règles communes]
Animation « content » : il sourit, lève le pouce d'une main, fait un petit hochement de tête, puis redescend le bras.
```

### 5. Content — applaudit

```
[Règles communes]
Animation « content » : grand sourire, il applaudit devant sa poitrine (mains écartées / mains jointes en alternance).
```

### 6. Super content — saut bras en V

```
[Règles communes]
Animation « super content » : il s'accroupit un peu, saute en l'air bras levés en V, bouche grande ouverte de joie, puis retombe.
```

### 7. Super content — petite danse

```
[Règles communes]
Animation « super content » : petite danse joyeuse et simple sur place (pas de côté, bras qui balancent, épaules qui bougent), sans acrobatie, les deux pieds restent près du sol.
```

### 8. Pas bien — haussement d'épaules

```
[Règles communes]
Animation « pas bien » : moue déçue, il hausse les épaules paumes vers le ciel (« oh non… »), puis laisse retomber les bras.
```

### 9. Pas bien — secoue la tête

```
[Règles communes]
Animation « pas bien » : air un peu déçu, il secoue doucement la tête de gauche à droite, une main sur la hanche.
```

### 10. Pas bien du tout — tête dans les mains

```
[Règles communes]
Animation « pas bien du tout » : très déçu (pas en colère), il baisse la tête et la prend dans ses mains, épaules qui tombent, puis relève un peu la tête.
```

### 11. Pas bien du tout — tape du pied

```
[Règles communes]
Animation « pas bien du tout » : frustré mais pas méchant, tête baissée, poings le long du corps, il tape une fois du pied par terre, puis soupire.
```

Si tu veux plus de variété, on peut ajouter d'autres réactions sur le même modèle (par exemple « content : clin d'œil + pouce », « pas bien : main sur le front »).
