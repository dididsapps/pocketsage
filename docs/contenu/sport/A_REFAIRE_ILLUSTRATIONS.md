# Illustrations — tout ce qui reste à refaire (12 exercices, 6 images)

Colle d'abord le bloc RÈGLES dans une NOUVELLE conversation ChatGPT (Chat, Élevé) en joignant l'image de référence
« Le Ballon à deux », puis les messages 1 à 6, un par un.

```
RÈGLES pour toutes les images de cette conversation (même style crayon de couleur à contour brun que l'image jointe, Sami et Lou identiques) :
1. Image 1536 × 1024, 2 rangées = 2 exercices, 2 à 4 cases par rangée, AUCUN texte.
2. Sécurité genou : un pied levé se pose contre la CHEVILLE ou le MOLLET, jamais sur ou près du genou.
3. Sécurité nuque : dans toute posture tête en bas, la tête PEND simplement entre les bras, visage vers les genoux, jamais retournée ni tordue.
4. Côtés : quand je dis « l'autre côté », la case montre le membre OPPOSÉ (comme dans un miroir), clairement différent.
5. Mouvement : chaque case est NETTEMENT différente de la précédente.
```
