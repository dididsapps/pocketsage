# Illustrations lot 1 — méthode « bande de cases » (comme l'image de référence)

Où : **ChatGPT, mode Chat** (pas Work), réflexion **Élevé**. Joins l'image de référence « Le Ballon à deux ».
Colle le bloc. Il dessine un exercice par image ; réponds « suite » pour le suivant. Enregistre chaque image
sous le nom donné (ex. `DF-003.png`) et envoie-les à Claude par paquets (zip) : Claude découpe les cases,
vérifie les postures et intègre.

```
Je veux des illustrations d'exercices pour enfants EXACTEMENT dans le style de l'image jointe
(crayon de couleur, contour brun épais, mêmes personnages, fond blanc, cases à bord fin).

RÈGLES
- Utilise le générateur d'images (pas de dessin en code, pas de schéma, pas de mannequin articulé).
- Pour CHAQUE exercice de la liste : UNE seule image au format paysage 1536 × 1024, comme la référence,
  qui contient 2, 3 ou 4 cases côte à côte = les étapes du mouvement dans l'ordre.
  • posture tenue : 2 cases (entrée, posture finale) ;
  • aller-retour : 3 cases (départ, position haute, retour à mi-chemin — jamais identique à la première) ;
  • exercice des deux côtés : la dernière case montre l'autre côté.
- Dans les cases : même taille de personnage, même cadrage, même position au sol, personnage entier avec une marge.
- Enfant seul = « Sami » (environ 7 ans, cheveux châtains bouclés courts, t-shirt vert sauge, legging gris clair,
  pieds nus). Duo = Sami + l'adulte « Lou » de la référence.
- Postures anatomiquement exactes selon la consigne (côté, coude, genou, nuque dans l'axe du dos).
  Aucun texte, aucun chiffre, aucune flèche sauf petites lignes de mouvement.
- Un exercice par réponse. Écris juste avant l'image son nom de fichier (ex. « DF-003.png »), puis la légende
  de chaque case (8 mots maximum chacune). Quand j'écris « suite », passe au suivant.
```
